# 台股當沖候選

每個交易日盤後由 GitHub Actions 掃描全部上市櫃股票，列出隔天的當沖候選和進出場價位，並做紙上追蹤。

> 僅供參考，不構成投資建議。系統不會自動下單，也不看新聞。目前規則的回測績效為負，請勿直接照著下單。

## 怎麼看結果

打開 GitHub Pages 的報告網址，或本機雙擊 `run_now.bat` 跑一次後看 `docs/index.html`。

## 怎麼選股

1. **排除：** 非當沖標的或暫停當沖、注意股、隔日仍在處置期間、漲跌停收盤、股價超出範圍、跳動成本過高、當沖過熱、振幅不足。
2. **評分：** 依振幅、當沖金額、跳動成本、當沖熱度、法人買賣超換算成 0～100 分。
3. **方向：** 依法人買賣超、收盤位置、5 日均線判斷偏多或偏空。
4. **價位：** 以 5 日平均振幅為單位，用固定公式算進場、停損、目標價。

注意或處置名單抓不到時，該市場的個股一律不推薦。

## 紙上追蹤

系統不會下單，只把「現行規則」和「近目標＋硬停損」的計畫在隔日開盤前記到 `data/history_paper.csv`，隔天收盤後再用日 K 算結果。隔日開盤後就不能再更動當天的計畫。報告會顯示累積筆數和是否達標：至少 100 筆、扣成本與滑價後每筆平均為正、最差一筆不超過 5%。

## 調整設定

只要改 `config.toml`：篩選門檻、評分權重、停損距離和交易成本。下次執行就會生效，舊的紙上紀錄不會變。

## 第一次在 GitHub 上設定

1. **GitHub Pages：** Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/docs`。
2. **Email（選用）：** Settings → Secrets and variables → Actions，新增以下三項：
   - `SMTP_USER`：寄件的 Gmail 地址
   - `SMTP_PASS`：Gmail 的「應用程式密碼」（不是登入密碼）
   - `MAIL_TO`：收件地址，多個用逗號分隔
3. **測試：** Actions → Taiwan day-trade screener → Run workflow，可勾選「寄一封測試信」。

排程是週一到週五台北時間 19:00，20:30 重試；GitHub 的排程可能延遲。休市日或當天已完成時不會做事。

## 本機執行

```sh
python -u daytrade.py               # 抓今天的資料並產生報告
python -u daytrade.py backfill 20   # 用過去 20 個交易日回測規則
```

需要 Python 3.11 以上，不用安裝其他套件。
